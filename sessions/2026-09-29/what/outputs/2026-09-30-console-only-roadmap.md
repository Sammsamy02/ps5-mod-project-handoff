# Console-only product requirements — September 30, 2026

The user's latest table is the intended coverage, not evidence that its backends exist. The finished private Nexus app must run entirely on the PS5: account sign-in, catalog navigation, authorized downloads, archive options, analysis, conversion, caching, installation, removal and validation. A computer may build and test the app once. A computer, phone or AI service must not be required to prepare or run a supported mod. Nexus and other explicitly authorized content services remain network dependencies.

Use shared format, engine and runtime modules. The first test title is selected at test time and may be any game; the previously supplied Stellar Blade version is historical context. Production code must not select implementations by game/title/mod ID. Evidence-based engine/build profiles may constrain formats and ABI contracts, but source-to-target mappings require evidence. Unknown engine structures, addresses, tiling, shader bindings or executable behavior must not be guessed.

User-facing classifications are Supported, Needs conversion, Unsupported and Failed. Supported requires an implemented PS5 backend and evidence for the applicable game/build and mod family. Needs conversion is installable only after a verified on-console converter produces a validated result. Missing or unverified backends, external-device/AI requirements and ambiguous analysis block installation with an actionable reason. Existing internal unresolved/unmeasured states remain evidence states; they must never silently become Supported. Failed describes a failed validation after installation, with rollback state reported separately.

Archive heuristics generate requirements and candidates, not definitive intent. A network import does not prove a mod is multiplayer, a bundled EXE may be optional, and texture memory cost cannot be inferred solely from archive size. Require the actual dependency/options/runtime contract; unresolved intent remains blocked with an accurate reason. Do not pretend a heuristic supplied that evidence.

Requested families: assets and data/params; UE4SS Lua/Blueprint; me3 file overrides; color effects/ReShade/depth effects; Unity IL2CPP/C#; automatic build-update matching; constrained DLL translation; shader matching; unknown-engine texture matching. Complex DLLs, ENB, unrecognized non-texture formats and online/co-op mods are excluded unless the user changes scope. No implementation or majority-of-Nexus coverage is established by this list.

Preserve original game files through overlays or redirects. The pasted Phase 10 in-place swap conflicts with that requirement; implement any future texture replacement through the same reversible overlay path. Uninstall must remove owned installed files and deactivate owned redirects, preserving user edits and unrelated files. A successful boot alone cannot prove correct gameplay or distinguish every mod failure from unrelated crashes.

A universal video-out hook, Sony shader writer, reliable engine-wide signatures, Unity runtime bridge and Windows/game ABI bridge are separate research deliverables. Shared CPU architecture, reflection, SPIR-V output or a matching image fingerprint is insufficient evidence that a mod runs. Broader engine-level automation remains the objective without per-mod hand patches.
