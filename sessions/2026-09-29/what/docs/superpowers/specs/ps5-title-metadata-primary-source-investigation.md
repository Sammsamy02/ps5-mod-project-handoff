# PS5 title metadata: primary-source investigation

2026-09-30. Read-only source research; only this note was written. No product/Git changes, console/FTP/device/game/account/Nexus traffic, deployment, rebuild or curl retry. Public source retrieval was bounded and held in memory, with no repository clone or downloaded tool execution.

The practical next provider should decode complete PS5 `param.json` metadata captured through an explicitly scoped, read-only filesystem seam. Sources establish useful paths and fields beyond the conflicting `app_info` structs, but do **not** establish this process's permissions, installed-title completeness or native operation on firmware 13.60. Cached metadata, mounted application, registered package and running process remain different observations. A name/version is descriptive; its metadata-file hash is not a build fingerprint.

## Retained observations and exact field profile

The existing [metadata observation](/WORKSPACE/.codex/worktrees/translation-core/what/.superpowers/native-observations/title-metadata-observation.json) contains 24 records explicitly marked `metadata_only`; observed `titleId`, `contentVersion`, `masterVersion` values are strings. The historical [base-listing result](/WORKSPACE/.codex/worktrees/translation-core/what/.superpowers/native-observations/title-base-listings.json) reports permission failures, while the later [LIST observation](/WORKSPACE/.codex/worktrees/translation-core/what/.superpowers/native-observations/title-LIST-observation.json) reports directory listings. This supports source/schema investigation, not current native permission or an installed/running inventory. No historical target ID is a branch or provider requirement.

Initial PS5 JSON profile: root object; required bounded ASCII `titleId`; optional string `contentVersion`; optional object `localizedParameters` with string `defaultLanguage` and locale objects containing string `titleName`. Preserve version exactly; absent version/name is unavailable. The first pure decoder selects only the explicitly declared default locale; configured locale and English fallback policies are outside this slice. Missing selected name remains unavailable rather than manufacturing a label. Discard URLs/account/provider auxiliary fields. `masterVersion` may remain a separate descriptive field later; it does not replace a missing content version. PS4 SFO and database AppInfoJson require separate typed decoders, not silent JSON fallbacks.

The upstream substring readers use 16 KiB prefix reads and can return a textual match without proving complete JSON. We should reuse schema facts, not that acceptance behavior. Reject duplicate keys, invalid UTF-8, malformed/trailing data, oversized strings and incomplete captures atomically.

## Smallest bounded provider step

First build a pure offline PS5 metadata decoder over borrowed immutable complete bytes and a trusted candidate ID; owning output has only title/display/version observations with sources, `build_fingerprint:null`, and no install/runtime authority. Proposed limits (policy, not upstream facts): 64 KiB input, depth 16, 4096 values+keys, 64 locale entries, existing inventory string limits; caller owns input/output/scratch, no accepted prefix on failure. Test generic non-game IDs, Unicode/locales, absent version, candidate-ID mismatch, duplicate/truncated/changed/oversized input and auxiliary-field omission.

Then add an injected read-only adapter restricted to a named source profile. Use source-grounded roots above, validated single path segments, regular-file/no-symlink checks, exact bounded reads and before/after file identity checks; charge all attempted directory/file operations and bytes to one aggregate budget. No recursion, writes, permission adjustments, arbitrary database-provided paths, or browser-supplied paths. Directory error, count cap or mutation cannot become a complete empty result. A mounted-root profile reports `source_scope:mounted_applications`; a metadata-cache profile reports metadata candidates. Neither is `running_processes` or a complete installed-title list. Keep the existing unavailable native default until the actual process/read profile is separately established; source code alone does not resolve FW13.60 permissions.

The current 128-record logical cap does not fit every snapshot in 8 KiB: a compact schema-shaped calculation gave **7714 bytes for 24 modest records, 10226 for 32, 40370 for 128**. Longer labels/provenance reduce that count. Preserve current whole-response overflow failure. For a real library, introduce coordinated bounded paging over one immutable, completely captured snapshot with opaque cursors, byte-limited pages, stable title keys, total count and explicit next-page/page-completeness fields. Do not publish a truncated subset as the current schema's complete inventory; the host/module/UI wire must change together before selectable paging is enabled.
