# Typed import installation: isolated Mac stage

**Result:** Isolated stage `cg-typed-import-install-20261013-15` connects the context-bound ABI bridge to the Windows import shim. Its public arbitrary-pointer publication path is removed. The replacement checks an internal integer-arity descriptor, stamps a context-bound trampoline into caller-owned writable memory, asks the caller to make that memory readable/executable, and publishes the address only after that step succeeds. The caller retains the mapping for the process lifetime. This is a host-tested installation seam, not a proved PS5 executable-memory route.

Only `KERNEL32!Sleep` and `KERNEL32!GetTickCount` are marked for installation. Their basic host behavior is exercised through real Win64-to-SysV calls, using the [documented one-argument `Sleep` signature](https://learn.microsoft.com/en-us/windows/win32/api/synchapi/nf-synchapi-sleep) and [zero-argument `GetTickCount` signature](https://learn.microsoft.com/windows/win32/api/sysinfoapi/nf-sysinfoapi-gettickcount). The host time source is an approximation of Windows timing behavior, and these checks do not establish every Windows edge case. Other cataloged bodies, including file, thread, dynamic TLS, and exception routines, remain unresolved imports. In the existing five-DLL static census, `Sleep` appears in TrueFOV and KismetDebuggerMod; `GetTickCount` appears in none of those five. All five DLLs still hit other load-time and import blockers.

The new host test passed **11/11** checks. It verified pre-install refusal, unknown and unreviewed-row refusal, invalid memory refusal, failed-seal refusal, invisibility during the seal callback, successful Mac RW-to-RX installation, actual calls through both published trampolines, and duplicate-install refusal. Regressions passed: context bridge **13/13**, registered imports **5/5**, TEB lifecycle **12/12**, static TLS **19/19**, loader preflight **27/27**, read-only TLS preparation on five unchanged DLLs **5/5**, and the existing synthetic PE fixture **11/11** with its pinned source hash unchanged.

The [incremental patch](typed-import-install-increment-20261013.patch) is based on the exact prior context-bridge stage. Its [manifest](typed-import-install-manifest-20261013.json) pins all six changed or added files; a scratch `git apply --check`, application, and byte comparison passed. [Evidence logs](typed-import-install-evidence-20261013.zip) include the fresh tests and patch replay. The shared candidate, Claude's work, kernel code, and original DLLs were untouched.

**Remaining:** The PE loader does not yet install these wrappers or execute an unchanged gameplay DLL. The PS5 memory-protection/cache route, guest GS/TEB publication, Windows/MSVC CRT, UE4SS ABI, additional APIs, non-integer signatures, and cross-build game-target correspondence remain open. The project is **not** a console-only wait.
