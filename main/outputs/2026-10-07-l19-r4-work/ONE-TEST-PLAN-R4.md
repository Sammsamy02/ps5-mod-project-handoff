# R4 single-launch plan — not ready for launch yet

## Preconditions

Two full build artifacts must match; all package/import/source/provider checks pass.
Only runtime PRX changes in /data/plugins. Townfall must be closed. Preserve a fresh
live rollback download with SITE SELF decrypt-off; compare full hashes and SELF magic
before and after upload. Existing configs, original Lua mod and all game files stay
unchanged. New klog capture only. Confirm existing Ploader and kstuff health, including
not-paused evidence; an unknown toggle remains unknown. User launches once.

## User test once readiness is reported

Launch Townfall, load one playable save, wait for runtime/plugin notifications,
then press L3+R3. Leave the game running for read-only harvest. Report any menu,
Ploader failure or crash. Do not relaunch until evidence has been harvested.

## Meaningful target milestone

Compiled declaration provider logged with R4 profile digest; all 69 member facts and
seven slots accepted and published; startup progresses beyond the prior layout refusal.
A Ploader OK alone does not prove those milestones. Menu and spawn are distinct live
results. No assertion that this build must show the menu.

## Read-only harvest

Bind evidence to current launch using session/image/build/profile identities and klog.
Record admission source/elapsed and FName prologue/ByteProperty roundtrip; declaration
provider source/digest and preflight verdict; final startup/UE4SS line and any Stopping mod.
Record pad borrow/open/first-state path, L3+R3/F7 events, carrier counts, widget/viewport
lines and any crash module+offset. Save autotune.ini and sink listing without deletion.
Classify all shown blockers against the existing checklist and propose one next change.

## Rollback

Fresh preimage is retained locally. A restoration would upload only that exact runtime
PRX, with game closed and decrypt-off readback verification. Do not assume the standing
approval covers a failed-gate candidate or any other file/state change.
