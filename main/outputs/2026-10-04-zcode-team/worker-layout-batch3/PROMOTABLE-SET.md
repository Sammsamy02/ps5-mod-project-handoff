# PROMOTABLE-SET.md — what COULD be staged today, per entry, and what gates the rest

Team 2026-10-04-zcode-team / worker-layout-batch3. Machine source of truth: `dryrun/promotable-set.json` (generated by `bridge/width_contract.py` from the frozen width contract + the candidates profile + the predicate inventory; regenerate with the command in REPORT.md). Every value here is a CANDIDATE with cited origin; **nothing in this table is validated for any target** — 'COULD be staged today' means: IF the named predicate chain returns Validated for a mapped snapshot under the matched GUObjectArray hypothesis (and, for FField/FProperty, the batch2 variant discriminator settles UE5_FField), THEN the assembler (bridge `assemble_staged_pair_v2.py`) may emit that member. Widths are never invented: staging requires a compiled accessor width from the frozen contract (`ue4ss-native-layout-widths-1/coverage.json` + `ue4ss-native-layout-widths-2/coverage-delta.json`).
