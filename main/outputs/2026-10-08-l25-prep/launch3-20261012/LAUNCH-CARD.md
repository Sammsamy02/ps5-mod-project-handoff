# Townfall launch card: launch 3 (B6: memory fix + diagnostics)

Goal: no crash; spawner, SpeedHack and minimap keep working past 5 minutes; the self-test finishes all 168 checks;
find out whether the early lag is still there. Controller only (keyboard keys
never reach mod hotkeys on PS5).

## Before the launch (Claude, each with your OK, game CLOSED)
1. Upload the changed files: mod list, pad mapping, SpeedHack (replaces
   InfiniteStamina), our zzdiag v12. The PS5's old copies are backed up first.
2. Create SpeedHack's save folder; check all 30 mod-list files.
3. Install the runtime (B5 or B6), start the mod loader and the log capture.
   **Then start Townfall within 2 minutes.**

## The launch (you)
1. Start Townfall, load your save, wait about a minute in the world.
2. Note any **stutter** in the first 3 minutes (when it starts, when it stops).
3. **Spawner**: L3 + R3 opens the menu. D-pad up/down moves, left/right pages,
   Cross spawns one item, L3 + R3 closes. Do this **3 times** over the session.
4. **SpeedHack**:
   - TouchPad + R1 = player speed (press a few times; it cycles up to 5x and back)
   - R1 + R2 = game speed (cycles; 0.5x is slow motion)
   - TouchPad + L2 = infinite stamina on/off
   - L1 + L2 = reset everything to normal
   (TouchPad = press the big touch pad down while pressing the shoulder button.)
5. **Self-test**: press L1 + R1 once. **Keep playing about 5 minutes** after that
   (it needs time to finish). It starts by itself 3 minutes after loading if you
   don't press it.
6. Minimap: works as before (F5 menu via keyboard is fine for the minimap).
7. Quit normally (PS button -> close game), tell Claude "game closed".
