- **PASS** -- call completed under pcall with the expected result type

  observed value: read it even on PASS, e.g. `FName-eq eq=false` on
  console means the `__eq` metamethod did not fire -- a real finding).
- **FAIL** -- Lua error (tail shown) or a failed semantic assert. This is

- **SKIP** -- runtime-conditional precondition absent (no-valid-pc = run
  fired before the player was in-world; no-array/no-enum = that engine
  object does not exist in this game). Not a failure; re-run in-world.
- Static **SKIP-\*** lines in the preface are by-design non-calls (task
  law: no persistent writes, no constructs, no spawns, crash-law).
- A hard native crash mid-run = the progress marker names the API; the
  next launch logs `CRASH (resumed)` for it (NEVER force-kill to test).
