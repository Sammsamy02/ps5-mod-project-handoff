UE4SS CRITICAL GAP
A real owning live-module facts supplier, validated native target structure/build
layouts, callable engine/reflection functions and real game-thread delivery remain
necessary. UE4SSProgram source/init path exists but successful engine-bound startup
and Item Spawner do not. The latest Tick source route does not replace these facts.

DLL CRITICAL GAP
The tested DLLs are deliberately small freshly compiled owned examples with an
admitted subset of PE/Windows behavior. Real downloaded mods may require native
engine hooks, broader Windows APIs/CRT, static TLS, C++ unwind/SEH, data structures,
code generation or source recompilation. No arbitrary DLL->PRX binary converter
or complete Windows environment exists. A single simple DLL pass does not remove
those runtime requirements. Compatibility should refuse missing requirements
accurately and expand through real generic implementation.

INSTALLER/APP GAP
Some conversion hooks remain placeholders; service contracts may be spec-only
or capability-disabled. Native PS5 sign-in/catalog/download/preparation/install/
activation still need coherent end-to-end completion. A readable catalog and an
installed file cannot stand in for a working runtime. Multi-engine research and
script-role categorization are future work inputs, not actual shipped bridges.
