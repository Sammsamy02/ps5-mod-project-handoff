LIMITS
Some generic conversion hooks in Claude's source were placeholders. The imported
backend did not deliver a real Unreal engine context or Windows DLL backend.
Research JSON for Decima/Unity/REDengine/other engines is a map of future work,
not proof those mods execute on PS5. 'PS5-ready bundle' means a console reader can
consume that bundle, not that the contained Windows script/asset/code is already
translated into a valid game runtime. Keep these meanings separate.
