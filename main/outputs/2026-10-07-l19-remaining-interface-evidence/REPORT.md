# Saved-image UClass.Interfaces evidence

The saved authenticated image proves `UClass.Interfaces` at native offset **0x1D8**, with a **16-byte array header**. The existing selected-target binding provider and genuine public `GetInterfaces()` value type both yield width 16. This fact needs no additional width adapter. It is a separate evidence candidate; the frozen R2 profile, sources, maps, and configuration remain unchanged.

`INTERFACE-FACTS.json` records 231 exact instruction windows, two exact native class names, and a unique standard DT_RELA entry. All windows use actual ELF PT_LOAD mapping rather than file-offset identity: image-vaddr 0x324550 maps to file offset 0x328550. The authenticated image has SHA256 `3b6cfad47dd17fea17d429bce80ae374d1fd2ef8894672cce63f5a26853622fc`, size 194241424; runtime address adds module base 0x400000.

Native predicate 0x324550 checks the requested class's interface flag, calls the native getter 0x39FA20, and rejects that base class. Getter 0x39FA20 registers the exact UTF-16 name `Interface` in `/Script/CoreUObject`; its registration flags include the same 0x4000 bit. The predicate begins with the supplied native class and follows superclass pointers at +0x40. For each class it reads the count as a dword at +0x1E0, the data as a qword at +0x1D8, scales the count by 16, advances entries by 16, and reads each entry's native class pointer at +0. Its ancestry comparison against the requested interface returns true on a matching interface class; exhaustion returns false.

The named native `Class` descriptor installs vptr 0x7ED7A28. Its unique standard DT_RELA record at file 0x93735D8 targets vptr+0xC8 = 0x7ED7AF0 with info 8 and addend 0x323B00. That native class function stores its class `this` in RBX and passes `this+0x1D8` to array serializer 0x332600. The serializer treats its array argument as data pointer +0/8B, count +8/4B, and capacity +0xC/4B; it scales count/capacity by 16 and allocates/reallocates 16-byte elements with alignment 8. The containing class function independently addresses capacity at +0x1E4. These native paths establish the whole 16-byte array header, rather than inferring a class total from member extent.

The array element initializer at 0x332820/0x332830 stores a qword at element+0, dword at +8, byte at +0xC, and advances by 16. The class pointer at element+0 is independently used by the interface predicate and function lookup. The selected public `FImplementedInterface` declaration has the same stride and fields; its target layout is compiled separately. Auxiliary native field roles are not needed to publish `Interfaces`, and the public declaration was not used to guess the native offset.

Independent function lookup 0x3254C0 reads the same class array at +0x1D8/count+0x1E0, scales and advances by 16, reads each entry class at +0, and recursively calls itself to search that class. It then searches the native superclass at +0x40. This matches the retained selected field iterator's actual interface and superclass traversal requirements.

`TARGET-WIDTH.json` records a successful selected-target compile. Static assertions prove actual legacy `Find("UClass","Interfaces") == 16`, actual public `GetInterfaces()` value width 16, and selected `FImplementedInterface` stride 16 with Class/PointerOffset/bImplementedByK2 at 0/8/0xC. `InterfaceWidthControlFacts` emits `(16,16,16,0,8,12)` for independent object inspection. No getter or engine call executes.
