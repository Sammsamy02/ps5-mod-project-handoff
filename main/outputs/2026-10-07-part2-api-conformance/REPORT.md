The release defines functions at chunk load but calls only six RegisterKeyBind registrations, optional RegisterLoadMapPreHook and the Loaded print there. F7 dispatches `toggleMenu`; `showMenu(true)` scans the database before `buildUI`. Scan conversion comes before UEHelpers/controller/UMG lookup. UEHelpers import initializes two invalid caches; its controller search falls back only on a falsy collection. Root `Create` precedes conditional StaticConstructObject fallback. UMG tree construction evaluates class lookup and FName before StaticConstructObject. Native nested font/vector writes can silently fail under the release's pcall paths, so readback/restore is explicit in the probe.

Enter first resolves controller/pawn fallbacks, reads location/rotation, and performs the 12-argument ground trace. It then looks up the cooked pickup class; only an invalid class triggers LoadAsset and another lookup. BeginDeferredActorSpawnFromClass/FinishSpawningActor precede pickup validation, ItemId comparison, quantity/auto-destroy writes and enabled/visibility/collision changes; failure conditionally destroys the actor. Map cleanup occurs independently on a transition. The runner does not implement or autoexecute this actor-spawn chain. All 33 actual reflected names remain listed as untested in the manifest; the original mod must still visibly open/close/reopen its own readable UMG menu, lock/unlock input safely and spawn a real valid pickup before the broader ladder can advance.
