# Whole logical group-buffer verification

`group_bytes.py` verifies a chosen whole raw09 `.bin` against a revalidated type8 manifest, genuine-format local intake receipt and actual full pinned v8 TOC. It writes metadata only and opens no UCAS path. The shared `manifest_v1.verify_logical_chunk` gate performs the exact parser/source SHA, full lookup, row/raw-ID/type, length, metadata IoHash and actual whole-buffer BLAKE3 checks. The adapter requires explicit actual owner TOC SHA/container bytes/row and length=manifest compressed_size. Supplied bytes are already transport-decoded logical chunk bytes; this utility does not reconstruct transport blocks.

Equal group sizes use the pinned generic source's stored-group semantics. Sorted member views follow actual admitted buffer ranges; a leading prefix is unassigned. Disordered member arrays are allowed for offset views but do not become writer-order/group-ID proof. Output SHA256 fingerprints describe view contents only. Unequal sizes still permit whole-buffer verification but return CODEC_REQUIRED and zero views. No codec, stored shader hash, group-ID derivation, instructions, target support or compatibility is established. Source basis: ../group-byte-intake-audit/DESIGN.md, MIT retoc d034ade1ae8117d4786eaf6b0418d4cf48474d7f shader_library.rs249–305,1029–1057,1109–1173.

Use `python3 group_bytes.py --help`. Required pairs are `--manifest-payload/--manifest-receipt/--manifest-id` and `--group-payload/--group-receipt/--group-id`; owner flags are `--owner-toc-sha`, `--owner-container`, `--owner-row`. Optional repeated `--shader-index` selects≤16 distinct actual group members; omission selects all. Optional `--out` creates a new JSON inside this folder; otherwise stdout reports summary. All fixtures under synthetic/ are generated small data. synthetic-command.json retains the successful CLI command; choose a fresh output filename to replay.

Bounds: manifest/group4MiB each and8MiB combined; receipt2MiB; inherited fullTOC32MiB and overlay512KiB; verified manifest reader128KiB; output8MiB. Existing vector/reference caps remain. Reader/dependencies execute only already-hash-checked bytes with __file__/__name__ preserved. Sources are rechecked after both manifest and group work. Owner TOC may differ from manifest TOC. Receipt declarations are preserved (including slice/full scope) but are not authenticated execution records; actual provided chunk/TOC integrity is checked independently. No full original UCAS identity is inferred from a slice receipt. Exclusive output under an ordinary local-filesystem threat model; not adversarial directory-race hardening.
