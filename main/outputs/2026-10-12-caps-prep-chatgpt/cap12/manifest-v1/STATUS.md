# Source-specified version1 metadata decoder (Mac-only)

manifest_v1.py implements the public MIT retoc version1 type8 header format pinned at d034ade1ae8117d4786eaf6b0418d4cf48474d7f. Format source SHA256 is6bbdf0886b2a0aa4a5bc602a3392f014e362b0b63ea7d473918c792091c53b43. See ../manifest-format-audit/FORMAT.md and public-source-receipt.json for exact source/license/line provenance. This is original Python utility code; no Epic source copied.

The parser reads full20-byte stored map/shader hashes and raw12-byte group IDs. Explicit shared index arrays resolve map-local slots to library shader indices. Overlapping/shared array ranges are allowed. Packed frequency/group/offset fields and group membership determine metadata spans ordered by uncompressed offset, rather than array order. Spans are not verified payload or instruction boundaries. Nonzero unclaimed group prefixes are explicitly reported. Compressed groups retain unknown codec; no decompression or type9 reads occur.

CLI admission requires a unique verified type8 row from an existing local_shader_intake.py receipt. It checks source hashes for the original overlay parser (fixed current pin), local TOC and chosen payload, full TOC lookup validation, exact chunk ID/row/type, TOC logical length/metadata IoHash, receipt length/hash, and actual whole-payload BLAKE3-20. Inputs are rehashed before output. UCAS paths are not opened. As in existing intake, strict_admission=False relaxes reserved header bytes; format/profile/EOF and lookup checks remain active.

Caps: chosen .bin4MiB, receipt2MiB, original parser512KiB, TOC32MiB, each vector65,536 elements, aggregate vector elements131,072, referenced map/group slots131,072 and JSON output8MiB. Empty tables, unsupported version/trailers, duplicate identities, inconsistent parallel counts/ranges/indices/group ownership/sizes/offsets refuse. These are a deliberately restricted utility profile, not proof every possible version1 archive satisfies them. CLI writes only an exclusive new output file within this folder and refuses existing destinations/input clobber.

Fifteen focused tests pass. They cover nonidentity mappings, shared overlapping ranges, packed fields and offset-order spans, compressed metadata without codec execution, truncation/count bombs, wrong version/trailers/empty tables, count/range/group inconsistencies, source preservation, wrong receipt type/duplicate row, wrong SHA/receipt IoHash/actual BLAKE3, wrong TOC row/parser pin, and existing-output preservation. tdd-red.txt records missing-parser failures; tdd-green.txt is the final run. Initial fixture metadata offsets were corrected before the passing run; no original files changed.

synthetic-fixture/ and synthetic-replay-bounded.json are artificial evidence (synthetic-replay.json is the prior run): two maps, three shader records, one group; no real shader payload was inspected. The real target format, frozen object+212 mapping, object+216/hash relationship, type9 bytes, code-hash equality, native shaders and compatibility remain unproven. This reduces the next step to supplying an actual bound type8 .bin/receipt and inspecting its actual resource-hash and explicit slot mapping.

Loading/bounded-read correction: execution uses exactly the already SHA-checked parser bytes in the spec-created module namespace, retaining __file__/__name__. Initial and final reads use the same cap+1 reader with descriptor/path st_dev, inode, size and mtime checks. A behavioral local-copy race test failed before this fix: changing the parser path after hashing executed appended bytes. It now refuses the changed source without executing those bytes. The original parser was never edited. tdd-red-loading.txt records that regression; the final suite has15 passing tests and the synthetic CLI replay passed again.
