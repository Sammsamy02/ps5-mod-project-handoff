# Focused analyzer review (Mac-only; proposals, no live edits)

Inspected shader-fallback/classify_materials.py and fallback.md; reran analyzer with explicit destination. Its output writes only the requested JSON. Existing 15 pinned checks reproduce one corpus; they are not robustness or overlay-safety tests.

1. **Store coverage mismatch:** base_replaced tests membership in the pakchunk0 store; path matching reads five TOCs. Fresh result is 68 path overlaps but 66 store overlaps. Proposal: keep separate path_overlap, store_evidence_available and replacement_identity_verified fields. Load a source-tagged store for every relevant base container, or mark UNKNOWN; never call a missing store entry “added”. Add the pakchunk10 missing-evidence case as a regression before actions.
2. **Identity missing:** SUBSTITUTE_BASE_EXPORT checks only base store pid presence, not matching primary export name/class as required by fallback.md §A. HIDE also selects a fixed game's material automatically. Proposal: require package+export+class identity receipts and verified target export/import compatibility. An unverified target or identity returns REVIEW_REQUIRED with no actionable directive. Do not auto-hide on a name heuristic.
3. **Generic rules missing:** absolute worktree, corpus paths/counts, Townfall content prefix and M_FluxSurfaceInvisible target are hardcoded. Proposal: explicit immutable intake manifest, engine-level content-root handling, candidate discovery from the base export/class index and capability metadata. Keep this Leon dataset as a fixture. Rename name-based role/invisible guesses as hints and require independent intent evidence before changing visuals.
4. **Evidence overclaim:** arbitrary DXBC/DXIL strings and dependency ancestry do not validate executable shader containers or the direct material-parent relationship. Proposal: validate container bounds/chunks; resolve parent edges specifically; record UNKNOWN on unreadable chains. Zero PS5 tokens or missing hash alone is insufficient. Rename “shader-broken” to “PC shader evidence; PS5 usability unproven”.
5. **Parser integrity:** container version is read but not rejected, view offsets/counts are not fully bounded, negative counts can be accepted as empty, duplicate pids overwrite, non-type1 TOC rows are collapsed into type2. Proposal: strict signature/version support, count/range/graph-cycle guards, unique identity checks and exact chunk-type retention; malformed/truncated/unknown inputs fail closed. Reject zero analyzed items.
6. **Overlay proof missing:** analyzer only produces instructions; it neither builds nor verifies derived rows. Proposal: builder consumes a validated manifest, hashes inputs before/after, writes a separate derived artifact, reparses output and verifies retained/import closure, store/hash consistency and every touched chunk. Suppression removes both replacement store entry and corresponding chunk rows; repoint uses a validated export reference, never text-byte search/replace. Keep original files immutable. Emit touched-row counts, output hashes, look_loss warnings and an uninstall receipt. Nonzero count plus no unresolved identities required before installation.
