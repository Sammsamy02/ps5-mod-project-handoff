These mods do not require arbitrary reflected gameplay value writes in the inspected non-GUI paths. EventViewer changes its own queue/counters; Kismet mutates the native dispatch table and its breakpoint/pause state, reads bytecode/frames/property values, and delegates to original handlers. Calling the latter a generic field setter would silently change its meaning.

## Integration boundary

The currently retained global hook layer provides callback signatures, options, IDs and executor-draining removal. Native layouts provide admitted member/vtable metadata. The selected UFunction thunk route supplies bounded per-function pre/post callbacks with original forwarding. None alone gives EventViewer global three-family trace coverage or Kismet expression-table pause semantics. The cap09 child lease prevents finalization while a mod object is owned; it does not retire these singleton/global callbacks or paused expression hooks. Preserve full requirements and disclose any future source adaptation. No runtime bridge or patch is staged, and no build, console test or compatibility pass is claimed.
