## Production change and choice

Exactly one production TU differs from l15: the packaging runtime-start bridge. Initializer/admission, FName ABI/signature/roundtrip headers, pad, selected Lua runtime and unmodified PC release bytes are unchanged. [Source delta](/WORKSPACE/.codex/worktrees/translation-core/what/outputs/2026-10-07-l16-local-handles/receipts/SOURCE-DELTA.json) · [diff](/WORKSPACE/.codex/worktrees/translation-core/what/outputs/2026-10-07-l16-local-handles/reports/BRIDGE.diff).

During module_start the game exclusively creates and fully opens a bounded bank of64 read/write probe files (flags O_RDWR|O_CREAT|O_TRUNC|O_NOFOLLOW|O_EXCL, target0xF02, mode0600), before ploader restores access. Each delayed attempt consumes one handle once: fresh page-bounded sceKernelWrite copyin, exact sceKernelPread readback at offset0 through that SAME descriptor, then close. No late create, lookup, reopen, seek, recycled file offset or cached prologue replaces the check. Each path includes process/generation/ordinal; address is logged separately because it is unknown at startup. Evidence files are retained; unused descriptors close at failed startup or acknowledged/destructed-owner stop. A close error refuses success, logs the failure, and does not justify retrying a potentially retired descriptor. Process exit is final OS descriptor reclamation.

Retained handles are more robust for this experiment than startup caching: a cached or disk-derived prefix can miss a patch after startup and before the first engine call. A later byte comparison must still refer to this process's live bytes. Startup caching would be useful as labeled diagnostic corroboration, not the sole live signature witness. We therefore do not weaken l15's freshness, exact signature, fault history, cancellation, shared deadline or roundtrip checks.

Acquisition is limited to64 handles plus the inherited parent and a5,000ms scheduling budget. The shared60,000ms admission budget remains unchanged. An in-flight OS/native call, diagnostics and necessary cleanup cannot be preempted: these are scheduling/refusal budgets, not hard wall-clock promises. Host admission cases include60,000ms refusal and61,000ms with a deliberately slow already-entered query, below the300,000ms outer startup deadline. The bank introduces descriptor/empty-file pressure and actual startup latency must be measured on PS5. Exhaustion/acquisition failure refuses without late fallback creation.

Review caught an inherited stop-exception leak. The bridge now closes after successful owner destruction, which joins its initializer, and on an empty owner even if stop reported false. It does not close under a live initializer. Single initializer serialization is still required; no new concurrent debugger/console caller was added. Safe engine-hook unload is a separate unproved contract.
