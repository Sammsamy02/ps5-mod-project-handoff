1. OWNERSHIP / LIFETIME
The current code has one central bank owner and an exclusive in-place reservation, not a moved owning consumer object. g_copyin_probe_nonce++ reserves a slot. Its descriptor remains in the table during use; the table entry is set to -1 after exactly one close attempt. Normal error-return paths converge on close. Stop joins/destroys the one initializer before releasing remaining table entries; empty-owner startup failure releases the bank. This is internally consistent ONLY under the existing single-initializer and serialized module-start/module-stop contract.
The bank, nonce, capture slots and fault ledger are not locked for arbitrary concurrent consumers. No multi-consumer support or TSan proof is claimed. The loader fills the bank before creating the initializer std::thread; later stop joins it before cleanup.
No close retry exists. The current close-error mock really closes the host fd before returning -1/EIO, so its receipt models the retired-fd case. A dedicated numeric-reuse sentinel test is still missing. FreeBSD close(2) documents retirement on errors other than EBADF: https://man.freebsd.org/cgi/man.cgi?query=close . This is relevant platform evidence, not direct proof of every Sony wrapper error. For an uncertain error we mark the descriptor retired, log and refuse; we do not risk closing a replacement descriptor by retrying.
C++ diagnostics throwing mid-probe do not have a per-attempt RAII closer; the descriptor stays bank-owned for subsequent owner teardown. A dedicated thrown-diagnostic test and resource-lifetime policy clarification remain useful.

2. EXISTING / MISSING EVIDENCE
Already tested: partial startup acquisition, startup failure/exception cleanup, positive partial writes, signed and zero-extended SCE EFAULT after a partial write, zero/oversized write counts, short readback refusal, read EPERM, close-error refusal, standalone exhaustion, source changes between attempts, expiry before/after operations, normal stop and actual owner destruction after injected stop exception.
Missing or unproved: TSan of SUPPORTED producer/initializer/join lifecycle; explicit fd-number reuse/double-close sentinel; acquisition failures EMFILE/ENFILE/EPERM/EEXIST at first and partial-bank positions; combined actual admission retries + finite bank exhaustion; actual game descriptor headroom; leftover file cleanup; interrupted I/O cases; exception diagnostics mid-operation. A multi-threaded consume stress test would exercise an unsupported API contract, so it cannot establish that arbitrary callers are currently safe. Add synchronization before introducing such callers.
The code's pread is ONE exact-length read (up to 4096 bytes) and conservatively refuses any short read. It does not loop on short pread. That prevents partial/stale bytes from being published but may reject otherwise recoverable I/O. The write path does loop on positive short writes. A partial write followed by EFAULT marks the whole requested range faulted and does not publish a prefix.
At most 64 probe descriptors + 1 parent are retained; lowering to 8-16 is not automatically correct without measuring how many checks/retries consume them. Files are retained as evidence, not unlinked, and no stale-file purge is implemented. Never perform broad deletion based only on a filename prefix.

3. DEADLINES — CORRECTED PRECISE CLAIM
Both clocks are std::chrono::steady_clock.
The 5000ms acquisition clock starts in module_start before opening the parent; it is checked before each sink creation. The initial credential diagnostics occur BEFORE that timer. The 60000ms shared admission clock is created LATER inside the initializer and covers admission/retry and the constructor witness. Therefore acquisition is OUTSIDE the admission budget, not charged inside it.
These are scheduling/refusal budgets. Diagnostics, OS calls, close cleanup, and worker join are not preempted. Hence neither '5s plus one call' nor 'the outer 300s deadline caps a hung syscall' is a complete hard bound. The outer 5-minute startup control is also cooperative and starts later during initializer setup; it throws only when its check runs again. No hard wall-clock hang guarantee is established.

static void bridge_copyin_path_diagnostic(const char *path)
{
    // Lossless ASCII, four little-endian bytes per repeated word. Length and
    // word order reconstruct the exact path without a new text logger/import.
    size_t n = 0;
    while (path[n] != '\0') ++n;
    ::diagnostic_event("pool_copyin_path_len", static_cast<uint32_t>(n));
    for (size_t i = 0; i < n; i += 4) {
        uint32_t word = 0;
        for (size_t j = 0; j < 4 && i + j < n; ++j)
            word |= uint32_t(static_cast<unsigned char>(path[i + j])) << (8 * j);
        ::diagnostic_event("pool_copyin_path_word", word);
    }
}

static void bridge_copyin_credentials(uint32_t phase)
{
    const int saved_errno = errno;
    ::diagnostic_event("copyin_cred_phase", phase); // 1 startup, 2 delayed
    ::diagnostic_event("copyin_uid", static_cast<uint32_t>(::getuid()));
    ::diagnostic_event("copyin_euid", static_cast<uint32_t>(::geteuid()));
    ::diagnostic_event("copyin_gid", static_cast<uint32_t>(::getgid()));
    ::diagnostic_event("copyin_egid", static_cast<uint32_t>(::getegid()));
    errno = 0;
    const int sandbox = sceKernelIsInSandbox();
    const int sandbox_error = l13_sink::error(sandbox, errno);
    ::diagnostic_event("copyin_sandbox_raw", static_cast<uint32_t>(sandbox));
    ::diagnostic_event("copyin_sandbox_available", (sandbox == 0 || sandbox == 1) && !sandbox_error ? 1u : 0u);
    ::diagnostic_event("copyin_sandbox_errno", static_cast<uint32_t>(sandbox_error));
    int jailed = -1;
    size_t size = sizeof jailed;
    errno = 0;
    const int jail_rc = sysctlbyname("security.jail.jailed", &jailed, &size, nullptr, 0);
    const int jail_err = l13_sink::error(jail_rc, errno);
    const bool known = jail_rc == 0 && !jail_err && size == sizeof jailed && (jailed == 0 || jailed == 1);
    ::diagnostic_event("copyin_jail_available", known ? 1u : 0u);
    ::diagnostic_event("copyin_jail_value", static_cast<uint32_t>(known ? jailed : -1));
    ::diagnostic_event("copyin_jail_raw", static_cast<uint32_t>(jail_rc));
    ::diagnostic_event("copyin_jail_errno", static_cast<uint32_t>(jail_err));
    errno = saved_errno;
}

static void bridge_copyin_directory_prepare()
{
    if (g_copyin_parent_fd >= 0) return;
    bridge_copyin_credentials(1u);
    const auto start = std::chrono::steady_clock::now();
    const int flags = O_RDONLY | O_DIRECTORY | O_NOFOLLOW;
    errno = 0;
    const int fd = sceKernelOpen(kProbeParent, flags, 0);
    const int err = l13_sink::error(fd, errno);
    ::diagnostic_event("pool_copyin_parent_flags", static_cast<uint32_t>(flags));
    ::diagnostic_event("pool_copyin_parent_raw", static_cast<uint32_t>(fd));
    ::diagnostic_event("pool_copyin_parent_errno", static_cast<uint32_t>(err));
    if (fd < 0 || err != 0) {
        bridge_copyin_file_failure(1, kProbeParent, flags, fd, err, 1);
        return;
    }
    g_copyin_parent_fd = fd;
    g_copyin_generation = static_cast<uint64_t>(std::chrono::duration_cast<std::chrono::nanoseconds>(
        start.time_since_epoch()).count());
    g_copyin_pid = static_cast<uint32_t>(::getpid());
    g_copyin_probe_nonce = 0;
    for (uint32_t i = 0; i < kCopyinHandleLimit; ++i) {
        auto& handle = g_copyin_handles[i];
        // Target address is unknown at startup; the delayed diagnostic records
        // it separately. PID/generation/ordinal make each process-owned sink unique.
        l13_format_probe_sink(handle.path, 0, i + 1);
        const auto elapsed = std::chrono::duration_cast<std::chrono::milliseconds>(
            std::chrono::steady_clock::now() - start).count();
        if (elapsed >= static_cast<int64_t>(kCopyinStartupBudgetMs)) {
            ::diagnostic_event("copyin_startup_timeout", static_cast<uint32_t>(elapsed));
            bridge_copyin_directory_release();
            return; // scheduling bound; cannot preempt a kernel call already entered
        }
        errno = 0;
        handle.fd = sceKernelOpen(handle.path, kCopyinSinkFlags, 0600);
        const int sink_err = l13_sink::error(handle.fd, errno);
        ::diagnostic_event("pool_copyin_open_flags", static_cast<uint32_t>(kCopyinSinkFlags));
        if (handle.fd < 0 || sink_err != 0) {
            bridge_copyin_file_failure(1, handle.path, kCopyinSinkFlags, handle.fd, sink_err, 1);
            handle.fd = -1;
            bridge_copyin_directory_release(); // no partial bank, no leaked owners
            return;
        }
    }
    ::diagnostic_event("copyin_startup_handles", kCopyinHandleLimit);
    ::diagnostic_event("copyin_startup_elapsed_ms", static_cast<uint32_t>(std::chrono::duration_cast<std::chrono::milliseconds>(
        std::chrono::steady_clock::now() - start).count()));
}
static void bridge_copyin_directory_release()
{
    for (auto& handle : g_copyin_handles) {
        if (handle.fd < 0) continue;
        errno = 0;
        const int raw = sceKernelClose(handle.fd);
        const int err = l13_sink::error(raw, errno);
        handle.fd = -1;
        if (raw != 0 || err) bridge_copyin_file_failure(4, handle.path, kCopyinSinkFlags, raw, err, 2);
    }
    if (g_copyin_parent_fd >= 0) {
        errno = 0;
        const int raw = sceKernelClose(g_copyin_parent_fd);
        const int err = l13_sink::error(raw, errno);
        g_copyin_parent_fd = -1;
        if (raw != 0 || err) bridge_copyin_file_failure(4, kProbeParent, O_RDONLY | O_DIRECTORY | O_NOFOLLOW, raw, err, 2);
    }
}

static void l13_format_probe_sink(char *out, uint64_t addr, uint32_t nonce)
{
    static const char prefix[] = "/data/plugins/modbridge-copyin-p";
    static const char hex[] = "0123456789abcdef";
    size_t o = 0;
    for (; prefix[o]; ++o) out[o] = prefix[o];
    for (int shift = 60; shift >= 0; shift -= 4) out[o++] = hex[(addr >> shift) & 15u];
    out[o++] = '-';
    for (int shift = 60; shift >= 0; shift -= 4) out[o++] = hex[(g_copyin_generation >> shift) & 15u];
    out[o++] = '-';
    for (int shift = 28; shift >= 0; shift -= 4) out[o++] = hex[(g_copyin_pid >> shift) & 15u];
    out[o++] = '-';
    for (int shift = 28; shift >= 0; shift -= 4) out[o++] = hex[(nonce >> shift) & 15u];
    out[o] = '\0';
}

extern "C" int bridge_write_copyin_capture(uint64_t addr, const uint8_t **out_bytes, uint32_t *out_len)
{
    if (out_bytes == nullptr || out_len == nullptr) return 0;
    *out_bytes = nullptr;
    *out_len = 0;
    for (uint32_t i = 0; i < 3; ++i) {
        if (!g_write_copyin_capture_valid[i] || addr < g_write_copyin_capture_addr[i]) continue;
        const uint64_t offset = addr - g_write_copyin_capture_addr[i];
        if (offset >= g_write_copyin_capture_len[i]) continue;
        const uint32_t remaining = g_write_copyin_capture_len[i] - static_cast<uint32_t>(offset);
        if (bridge_copyin_range_faulted(addr, remaining)) return 0;
        *out_bytes = g_write_copyin_capture[i] + offset;
        *out_len = remaining;
        return 1;
    }
    return 0;
}

// Scheduling deadline only: no new operation begins after it. Kernel calls,
// diagnostics and mandatory descriptor cleanup cannot be preempted here.
extern "C" int bridge_kernel_write_copyin_probe_until(uint64_t addr, uint64_t len,
                                                       uint64_t deadline_ms)
{
    if (!l13_sink::valid_range(addr, len)) return bridge_copyin_result(3, 0, EINVAL, 0);
    if (bridge_copyin_range_faulted(addr, len)) return bridge_copyin_result(0, 0, EFAULT, 0);
    for (uint32_t i = 0; i < 3; ++i) {
        if (g_write_copyin_capture_valid[i] && addr < g_write_copyin_capture_addr[i] + g_write_copyin_capture_len[i] &&
            g_write_copyin_capture_addr[i] < addr + len) g_write_copyin_capture_valid[i] = false;
    }
    if (bridge_copyin_now_ms() >= deadline_ms) return bridge_copyin_result(2, 0, ETIMEDOUT, 0);
    if (g_copyin_parent_fd < 0) return bridge_copyin_result(2, -1, ENOENT, 0);
    // No path lookup after startup: each fresh attempt consumes a preopened
    // exclusive sink exactly once. No cached prologue or recycled file offset.
    if (g_copyin_probe_nonce >= kCopyinHandleLimit) return bridge_copyin_result(2, 0, ENOSPC, 0);
    auto& handle = g_copyin_handles[g_copyin_probe_nonce++];
    if (handle.fd < 0) return bridge_copyin_result(2, -1, ENOENT, 0);
    const int fd = handle.fd;
    const char *probe_sink = handle.path;
    bridge_copyin_path_diagnostic(probe_sink);
    ::diagnostic_event("pool_copyin_probe_addr_lo", static_cast<uint32_t>(addr));
    ::diagnostic_event("pool_copyin_probe_addr_hi", static_cast<uint32_t>(addr >> 32));
    ::diagnostic_event("pool_copyin_probe_len", static_cast<uint32_t>(len));
    ::diagnostic_event("pool_copyin_open_flags", static_cast<uint32_t>(kCopyinSinkFlags));
    ::diagnostic_event("pool_copyin_open_mode", 0600u);
    ::diagnostic_event("copyin_retained_fd", static_cast<uint32_t>(fd));
    bridge_copyin_credentials(2u);
    int err = 0;
    uint64_t landed = 0;
    int64_t raw = 0;
    bool faulted = false;
    while (landed < len) {
        if (bridge_copyin_now_ms() >= deadline_ms) { err = ETIMEDOUT; break; }
        const uint64_t cursor = addr + landed;
        const uint64_t page_left = 0x1000u - (cursor & 0xfffu);
        const uint64_t chunk = len - landed < page_left ? len - landed : page_left;
        errno = 0;
        raw = sceKernelWrite(fd, reinterpret_cast<const void *>(cursor), static_cast<size_t>(chunk));
        err = l13_sink::error(raw, errno);
        if (err != 0 || raw < 0) {
            if (err == EFAULT) {
                faulted = true;
                g_copyin_faults.record(addr, len);
                ::diagnostic_event("pool_copyin_probe_fault_off", static_cast<uint32_t>(landed));
                ::diagnostic_event("pool_copyin_fault_addr_lo", static_cast<uint32_t>(cursor));
                ::diagnostic_event("pool_copyin_fault_addr_hi", static_cast<uint32_t>(cursor >> 32));
            }
            break;
        }
        if (raw == 0 || static_cast<uint64_t>(raw) > chunk) { err = EIO; break; }
        landed += static_cast<uint64_t>(raw);
        if (static_cast<uint64_t>(raw) != chunk) {
            ::diagnostic_event("pool_probe_op_rc", static_cast<uint32_t>(raw));
            ::diagnostic_event("pool_probe_stop_addr_lo", static_cast<uint32_t>(addr + landed));
            ::diagnostic_event("pool_probe_stop_addr_hi", static_cast<uint32_t>((addr + landed) >> 32));
            ::diagnostic_event("pool_probe_op_pagealign", ((addr + landed) & 0x3fffu) == 0 ? 1u : 0u);
        }
    }
    const uint32_t slot = g_write_copyin_capture_next;
    g_write_copyin_capture_valid[slot] = false;
    const uint64_t expected = len < 0x1000u ? len : 0x1000u;
    int64_t got = -1;
    if (faulted || landed != len || err != 0) {
        if (err != ETIMEDOUT) bridge_copyin_file_failure(2, probe_sink, kCopyinSinkFlags, raw, err, 2);
    } else if (bridge_copyin_now_ms() >= deadline_ms) {
        err = ETIMEDOUT;
    } else {
        errno = 0;
        // Pread does not depend on or change the write cursor. The handle was
        // opened O_RDWR at startup and is never replaced by a delayed reopen.
        got = sceKernelPread(fd, g_write_copyin_capture[slot], static_cast<size_t>(expected), 0);
        err = l13_sink::error(got, errno);
        if (err != 0 || got != static_cast<int64_t>(expected)) {
            if (!err) err = EIO;
            bridge_copyin_file_failure(3, probe_sink, kCopyinSinkFlags, got, err, 2);
        }
    }
    errno = 0;
    const int close_rc = sceKernelClose(fd);
    const int close_err = l13_sink::error(close_rc, errno);
    handle.fd = -1;
    if (close_rc != 0 || close_err) bridge_copyin_file_failure(4, probe_sink, kCopyinSinkFlags, close_rc, close_err, 2);
    if (faulted) return bridge_copyin_result(0, raw, err, landed);
    if (landed != len || err != 0) return bridge_copyin_result(2, raw, err, landed);
    if (close_rc != 0 || close_err) return bridge_copyin_result(2, close_rc, close_err, landed);

inline int error(int64_t raw, int saved_errno) noexcept
{
    const uint32_t bits = static_cast<uint32_t>(raw);
    if (raw >= INT32_MIN && raw <= UINT32_MAX &&
        (bits & 0xffff0000u) == 0x80020000u)
        return static_cast<int>(bits & 0xffffu);
    if (raw == -1) return saved_errno;
    if (raw < -1 && raw >= -INT32_MAX) return static_cast<int>(-raw);
    return raw < 0 ? EIO : 0;
}
inline bool valid_range(uint64_t addr, uint64_t len) noexcept
{
    return len != 0 && len <= 0x1000000u && addr <= UINT64_MAX - len;
}
struct FaultLedger {
    struct Range { uint64_t lo, hi; } ranges[64]{};
    uint32_t count = 0;
    bool saturated = false;
    void record(uint64_t addr, uint64_t len) noexcept
    {
        if (!valid_range(addr, len)) { saturated = true; return; }
        for (uint32_t i = 0; i < count; ++i)
            if (ranges[i].lo <= addr && ranges[i].hi >= addr + len) return;
        if (count == 64) { saturated = true; return; }
        ranges[count++] = {addr, addr + len};
    }
    bool overlaps(uint64_t addr, uint64_t len) const noexcept
    {
        if (saturated || !valid_range(addr, len)) return true;
        for (uint32_t i = 0; i < count; ++i)
            if (addr < ranges[i].hi && ranges[i].lo < addr + len) return true;
        return false;
    }
};

    return stopped ? 0 : 1;
}

bool RuntimeOwner::start()
{
    std::lock_guard operation(operations_);
    {
        std::lock_guard lock(signals_->mutex);
        if (signals_->status.state != RuntimeState::Prepared) return false;
        signals_->status.state = RuntimeState::Starting;
    }
    try { thread_ = std::thread(&RuntimeOwner::initialize, this); }
    catch (const std::exception& error)
    {
        std::lock_guard lock(signals_->mutex);
        signals_->status = {RuntimeState::Failed, error.what()};
        // RUNTIME-ACK point 4: the session failed before any engine work;
        // record and continue, never propagate from the acknowledgment.
        if (ack_) ack_->failed(1, error.what());
        return false;
    }
    return true;
}
bool RuntimeOwner::stop()
{
    // Check before operations_: another caller may already hold it while
    // joining us. The worker must never wait behind its own joiner.
    {
        std::lock_guard lock(signals_->mutex);
        if (signals_->initializer == std::this_thread::get_id()) return false;
    }
    std::lock_guard operation(operations_);
    {
        std::lock_guard lock(signals_->mutex);
        if (signals_->status.state != RuntimeState::Failed &&
            signals_->status.state != RuntimeState::Stopped)
            signals_->status.state = RuntimeState::Stopping;
    }
    backend_->request_stop();
    if (thread_.joinable()) thread_.join();
    {
        std::lock_guard lock(signals_->mutex);
        signals_->initializer = {};
        if (signals_->status.state != RuntimeState::Failed)
            signals_->status.state = RuntimeState::Stopped;
        // RUNTIME-ACK point 5: after stop() has joined the init thread, the
        // cooperative stop is the session's final acknowledged state; only
        // then is the retained descriptor released. The sink emits stopped
        // at most once per session (the init thread may complete the
        // Stopping->Stopped transition first; repeated stop adds nothing),
        // and a failed session keeps its failed line last.
        if (ack_ && signals_->status.state == RuntimeState::Stopped)
        {
            ack_->stopped();
            ack_->close();
        }
    }
    return true;
}

constexpr uint64_t kAdmissionBudgetMs = 60000;

struct Budget {
    uint64_t start_ms, deadline_ms;
    explicit Budget(uint64_t now, uint64_t duration = kAdmissionBudgetMs)
        : start_ms(now), deadline_ms(duration > UINT64_MAX-now ? UINT64_MAX : now+duration) {}
    bool expired(uint64_t now) const { return now >= deadline_ms; }
    uint64_t remaining(uint64_t now) const { return expired(now) ? 0 : deadline_ms-now; }
};
enum class QueryKind { Available, Unavailable, Unmapped };
struct Query {
    QueryKind kind = QueryKind::Unavailable;
    uint64_t start = 0, end = 0;
    uint32_t protection = 0, flags = 0;
    int raw_rc = 0;
};
enum class Verdict { Readable, Unavailable, HardNegative, Expired, Invalid };
enum class Source { None, VirtualQuery, CopyinCapture, ImageSegments };
struct Result {
    Verdict verdict = Verdict::Unavailable;
    Source source = Source::None;
    const char* note = "readability unavailable";
    uint64_t fault_address = 0;
    size_t fault_length = 0;
};
struct Range { uint64_t address = 0; size_t length = 0; };
inline bool valid_range(uint64_t address, size_t length) {
    return address != 0 && length != 0 && length <= UINT64_MAX-address;
}
inline bool overlaps(Range a, Range b) {
    return a.address < b.address+b.length && b.address < a.address+a.length;
}
struct Session {
    // Fail closed if bounded evidence storage fills: never forget a fault.
    Range faults[16]{}; size_t fault_count = 0; bool all_excluded = false;
    Range probes[16]{}; size_t probe_count = 0;
    bool shadow_attempted = false;
    bool excluded(Range range) const {
        if (all_excluded) return true;
        for (size_t i=0;i<fault_count;++i) if (overlaps(faults[i],range)) return true;
        return false;
    }
    void exclude(Range range) {
        if (fault_count == 16) all_excluded = true;
        else faults[fault_count++] = range;
    }
    bool probe_once(Range range) {
        for (size_t i=0;i<probe_count;++i)
            if (probes[i].address==range.address && probes[i].length==range.length) return false;
        if (probe_count==16) return false;
        probes[probe_count++] = range;
        return true;
    }
};
inline Result expired() { return {Verdict::Expired, Source::None, "one total admission deadline exhausted"}; }

template<class Ops>
Result coverage(Ops& ops, Budget& budget, uint64_t address, size_t length) {
    if (!valid_range(address,length)) return {Verdict::Invalid,Source::None,"invalid or overflowing exact range"};
    const uint64_t end=address+length;
    uint64_t cursor=address;
    for (unsigned regions=0; cursor<end && regions<128; ++regions) {
        if (budget.expired(ops.now_ms())) return expired();
        const auto query=ops.query(cursor);
        if (budget.expired(ops.now_ms())) return expired();
        if (query.kind==QueryKind::Unmapped)
            return {Verdict::HardNegative,Source::None,"VirtualQuery proved unmapped"};
        if (query.kind!=QueryKind::Available)
            return {Verdict::Unavailable,Source::None,"VirtualQuery unavailable"};
        ops.log_region(address,length,query);
        // EXACT means the result must contain this byte, not merely overlap
        // some later part of the range. Malformed replies prove nothing.
        if (query.start>cursor || query.end<=cursor || query.end<=query.start)
            return {Verdict::Unavailable,Source::None,"VirtualQuery returned non-containing or degenerate region"};
        if ((query.protection & 1u)==0)
            return {Verdict::HardNegative,Source::None,"VirtualQuery proved no CPU-read protection", query.start, static_cast<size_t>(query.end-query.start)};
        if ((query.flags & 0x10u)==0)
            return {Verdict::HardNegative,Source::None,"VirtualQuery proved uncommitted reservation", query.start, static_cast<size_t>(query.end-query.start)};
        cursor=query.end<end ? query.end : end;
    }
    if (cursor!=end) return {Verdict::Unavailable,Source::None,"VirtualQuery region limit reached"};
    return {Verdict::Readable,Source::VirtualQuery,"exact needed range mapped and CPU-readable"};
}

template<class Ops>
Result read(Ops& ops, Budget& budget, Session& session, uint64_t address, size_t length, uint8_t* destination) {
    if (!destination || !valid_range(address,length))
        return {Verdict::Invalid,Source::None,"invalid or overflowing exact range"};
    if (budget.expired(ops.now_ms())) return expired();
    const Range range{address,length};
    // Stored fault provenance is checked before any new proof; a later VQ
    // or prefix capture cannot erase a fault observed during this admission.
    if (session.excluded(range) || ops.known_fault(address,length)) {
        session.exclude(range);
        return {Verdict::HardNegative,Source::None,"range excluded by recorded fault"};
    }
    auto result=coverage(ops,budget,address,length);
    if (result.verdict==Verdict::HardNegative) {
        session.exclude(valid_range(result.fault_address,result.fault_length) ?
                        Range{result.fault_address,result.fault_length} : range);
        return result;
    }
    if (result.verdict==Verdict::Expired || result.verdict==Verdict::Invalid) return result;
    if (result.verdict==Verdict::Readable) {
        if (budget.expired(ops.now_ms())) return expired();
        ops.read_direct(address,length,destination);
        if (budget.expired(ops.now_ms())) return expired();
        return result; // optional oracle cross-check is disabled by default
    }
    if (budget.expired(ops.now_ms())) return expired();
    const uint8_t* bytes=nullptr; size_t captured=0;
    if (ops.capture(address,length,&bytes,&captured) && bytes && captured>=length) {
        if (budget.expired(ops.now_ms())) return expired();
        std::memcpy(destination,bytes,length);
        return {Verdict::Readable,Source::CopyinCapture,"exact needed bytes from owned copyin capture"};
    }
    if (session.probe_once(range)) {
        if (budget.expired(ops.now_ms())) return expired();
        const int probe=ops.probe(address,length,budget);
        if (probe==0 || ops.known_fault(address,length)) {
            session.exclude(range);
            return {Verdict::HardNegative,Source::None,"copyin fault; range excluded and shadow barred"};
        }
        if (budget.expired(ops.now_ms())) return expired();
        if (ops.capture(address,length,&bytes,&captured) && bytes && captured>=length) {
            if (budget.expired(ops.now_ms())) return expired();
            std::memcpy(destination,bytes,length);
            return {Verdict::Readable,Source::CopyinCapture,"exact needed bytes from owned copyin capture"};
        }
    }
    // The fallback is diagnostic corroboration only. Matching disk-image
    // identity never supplies live heap bytes or grants a direct read.
    if (!session.shadow_attempted && ops.shadow_enabled) {
        if (budget.expired(ops.now_ms())) return expired();
        session.shadow_attempted=true;
        ops.shadow(budget);
        if (budget.expired(ops.now_ms())) return expired();
    }
    return {Verdict::Unavailable,Source::None,"VQ/copyin inconclusive; shadow identity cannot prove heap readability"};
}

// Image metadata requires segment evidence first. VQ can veto the segment;
// only an unavailable API (not a malformed containing region) is optional.
template<class Ops>
Result read_image(Ops& ops, Budget& budget, Session& session, uint64_t address, size_t length, uint8_t* destination) {
    if (!destination || !valid_range(address,length))
        return {Verdict::Invalid,Source::None,"invalid image range"};
    const auto segment=ops.image_range(address,length);
    ops.log_image(address,length,segment);
    if (budget.expired(ops.now_ms())) return expired();
    const Range range{address,length};
    if(session.excluded(range)||ops.known_fault(address,length)) {
        session.exclude(range);
        return {Verdict::HardNegative,Source::None,"image range excluded by recorded fault"};
    }
    // Query even when the segment is missing: diagnostics must distinguish
    // an absent module segment from an OS mapping failure, without reading.
    auto cross=coverage(ops,budget,address,length);
    if(cross.verdict==Verdict::HardNegative){
        session.exclude(valid_range(cross.fault_address,cross.fault_length)?Range{cross.fault_address,cross.fault_length}:range);
        return cross;
    }
    if(cross.verdict==Verdict::Expired||cross.verdict==Verdict::Invalid)return cross;
    if(!segment.readable)return {Verdict::Unavailable,Source::None,segment.note};
    if(cross.verdict!=Verdict::Readable && std::strcmp(cross.note,"VirtualQuery unavailable")!=0)
        return cross;
    if(budget.expired(ops.now_ms()))return expired();
    ops.read_direct(address,length,destination);
    if(budget.expired(ops.now_ms()))return expired();
    return {Verdict::Readable,Source::ImageSegments,cross.verdict==Verdict::Readable?
        "segment proven; VirtualQuery corroborated":"segment proven; VirtualQuery unavailable"};
}

template<class Ops,class Attempt>
Result retry(Ops& ops, Budget& budget, Attempt attempt) {
    for (;;) {
        if (budget.expired(ops.now_ms())) return expired();
        auto result=attempt();
        if (budget.expired(ops.now_ms())) return expired();
        if (result.verdict!=Verdict::Unavailable) return result;
        const uint64_t remaining=budget.remaining(ops.now_ms());
        if (!remaining) return expired();
        ops.wait_ms(remaining<kRetryIntervalMs ? remaining : kRetryIntervalMs);
    }
}

namespace RC::Unreal::UnrealInitializer
{
    enum class StartupWaitStatus
    {
        Continue,
        Cancelled,
        DeadlineExceeded,
    };

    class StartupCancelled final : public std::runtime_error
    {
    public:
        StartupCancelled() : std::runtime_error{"Unreal initialization cancelled"} {}
    };

    class StartupDeadlineExceeded final : public std::runtime_error
    {
    public:
        StartupDeadlineExceeded() : std::runtime_error{"Unreal initialization startup deadline exceeded"} {}
    };

    // Optional cooperative bound for startup readiness waits. The owner creates
    // one immutable control before Initialize and shares its absolute deadline
    // across all retries. Cancellation/deadline checks run between opaque
    // engine calls; they cannot interrupt an engine call already in progress.
    struct StartupWaitControl
    {
        using Clock = std::chrono::steady_clock;
        std::function<bool()> IsCancelled;
        Clock::time_point Deadline{};
        std::chrono::milliseconds PollInterval{10};

        auto StatusAt(Clock::time_point now) const -> StartupWaitStatus
        {
            if (IsCancelled && IsCancelled())
            {
                return StartupWaitStatus::Cancelled;
            }
            return now >= Deadline ? StartupWaitStatus::DeadlineExceeded : StartupWaitStatus::Continue;
        }

        auto ThrowIfStoppedAt(Clock::time_point now) const -> void
        {
            switch (StatusAt(now))
            {
            case StartupWaitStatus::Continue:
                return;
            case StartupWaitStatus::Cancelled:
                throw StartupCancelled{};
            case StartupWaitStatus::DeadlineExceeded:
                throw StartupDeadlineExceeded{};
            }
        }

        auto RetrySleepForAt(Clock::time_point now, Clock::duration requested) const -> Clock::duration
        {
            if (StatusAt(now) != StartupWaitStatus::Continue || requested <= Clock::duration::zero())
            {
                return Clock::duration::zero();
            }

            auto sleep = requested;
            if (PollInterval > std::chrono::milliseconds::zero())
            {
                sleep = std::min(sleep, std::chrono::duration_cast<Clock::duration>(PollInterval));
            }
            return std::min(sleep, Deadline - now);
        }

        template <typename Now, typename Sleep>
        auto WaitForRetry(std::chrono::milliseconds requested, Now&& now, Sleep&& sleep) const -> void
        {
            const auto retry_deadline = now() + std::chrono::duration_cast<Clock::duration>(requested);
            while (true)
            {
                const auto current = now();
                ThrowIfStoppedAt(current);
                const auto remaining = retry_deadline - current;
                if (remaining <= Clock::duration::zero())
                {
                    return;
                }

                const auto slice = RetrySleepForAt(current, remaining);
                if (slice <= Clock::duration::zero())
                {
                    ThrowIfStoppedAt(current);
                    return;
                }
                sleep(slice);
            }
        }
    };

    inline constexpr std::chrono::minutes DefaultStartupWaitTimeout{5};
}

#include "runtime_owner.hpp"
#include <stdexcept>

namespace modbridge::native
{
struct RuntimeOwner::Signals
{
    mutable std::mutex mutex;
    RuntimeStatus status;
    std::thread::id initializer;
};
RuntimeOwner::RuntimeOwner(std::unique_ptr<RuntimeBackend> backend, std::shared_ptr<RuntimeAckSink> ack)
    : backend_(std::move(backend)), signals_(std::make_shared<Signals>()), ack_(std::move(ack))
{
    if (!backend_) throw std::invalid_argument("Native runtime backend is required");
}
RuntimeOwner::~RuntimeOwner()
{
    // Destroying the object on its own worker would free live program state.
    // There is deliberately no detached-thread fallback.
    if (!stop()) std::terminate();
}
bool RuntimeOwner::start()
{
    std::lock_guard operation(operations_);
    {
        std::lock_guard lock(signals_->mutex);
        if (signals_->status.state != RuntimeState::Prepared) return false;
        signals_->status.state = RuntimeState::Starting;
    }
    try { thread_ = std::thread(&RuntimeOwner::initialize, this); }
    catch (const std::exception& error)
    {
        std::lock_guard lock(signals_->mutex);
        signals_->status = {RuntimeState::Failed, error.what()};
        // RUNTIME-ACK point 4: the session failed before any engine work;
        // record and continue, never propagate from the acknowledgment.
        if (ack_) ack_->failed(1, error.what());
        return false;
    }
    return true;
}
bool RuntimeOwner::stop()
{
    // Check before operations_: another caller may already hold it while
    // joining us. The worker must never wait behind its own joiner.
    {
        std::lock_guard lock(signals_->mutex);
        if (signals_->initializer == std::this_thread::get_id()) return false;
    }
    std::lock_guard operation(operations_);
    {
        std::lock_guard lock(signals_->mutex);
        if (signals_->status.state != RuntimeState::Failed &&
            signals_->status.state != RuntimeState::Stopped)
            signals_->status.state = RuntimeState::Stopping;
    }
    backend_->request_stop();
    if (thread_.joinable()) thread_.join();
    {
        std::lock_guard lock(signals_->mutex);
        signals_->initializer = {};
        if (signals_->status.state != RuntimeState::Failed)
            signals_->status.state = RuntimeState::Stopped;
        // RUNTIME-ACK point 5: after stop() has joined the init thread, the
        // cooperative stop is the session's final acknowledged state; only
        // then is the retained descriptor released. The sink emits stopped
        // at most once per session (the init thread may complete the
        // Stopping->Stopped transition first; repeated stop adds nothing),
        // and a failed session keeps its failed line last.
        if (ack_ && signals_->status.state == RuntimeState::Stopped)
        {
            ack_->stopped();
            ack_->close();
        }
    }
    return true;
}
RuntimeStatus RuntimeOwner::status() const
{
    std::lock_guard lock(signals_->mutex);
    return signals_->status;
}
void RuntimeOwner::initialize() noexcept
{
    {
        std::lock_guard lock(signals_->mutex);
        signals_->initializer = std::this_thread::get_id();
    }
    try
    {
        std::weak_ptr<Signals> weak = signals_;
        backend_->initialize([weak] {
            if (const auto signals = weak.lock())
            {
                std::lock_guard lock(signals->mutex);
                if (signals->status.state == RuntimeState::Starting)
                    signals->status.state = RuntimeState::EngineInitialized;
            }
        });
        std::lock_guard lock(signals_->mutex);
        if (signals_->status.state == RuntimeState::Stopping)
            signals_->status.state = RuntimeState::Stopped;
        else
        {
            signals_->status = {RuntimeState::Failed, "Native runtime init returned without a stop request"};
            // RUNTIME-ACK point 4: init returned on its own without readiness.
            if (ack_) ack_->failed(1, "Native runtime init returned without a stop request");
        }
    }
    catch (const std::exception& error)
    {
        std::lock_guard lock(signals_->mutex);
        signals_->status = {RuntimeState::Failed, error.what()};
        // RUNTIME-ACK point 4: genuine startup error, including a typed
        // deadline/cancellation converted to an error by the backend.
        if (ack_) ack_->failed(1, error.what());
    }
    catch (...)
    {
        std::lock_guard lock(signals_->mutex);
        signals_->status = {RuntimeState::Failed, "Native runtime initialization failed with an unknown exception"};
        if (ack_) ack_->failed(1, "Native runtime initialization failed with an unknown exception");
    }
    // Completed thread IDs may later be reused by an unrelated caller.
    std::lock_guard lock(signals_->mutex);
    signals_->initializer = {};
}
