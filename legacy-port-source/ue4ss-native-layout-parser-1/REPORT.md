Pure native layout-pair parser, local source/build only. Header NativeLayoutFiles.hpp exposes Identity, Bitfield, Entry, Bundle and ParsePair in RC::Platform::NativeLayouts. It returns locally owned strings/vectors only after both files and matching declared identity validate. No binding, target identity proof, engine maps, network, console or external mutation.

Grammar: optional initial UTF-8 BOM, LF/CRLF, blank lines, spaces/tabs around tokens and whole-line ;/# comments. ASCII keys begin with a letter/underscore and contain letters/digits/underscores. Sections additionally accept canonical nested C++ names separated by ::, including UScriptStruct::ICppStructOps. Ordered lists, duplicate sections/keys, malformed names, unknown/missing NativeLayout metadata and embedded NUL refuse. Opaque nonempty printable-ASCII EngineRevision/BuildId values retain internal spaces, #, ; and = literally; they are untrusted data, never instructions. Numeric metadata uses unsigned decimal. Identity equality compares parsed fields and exact opaque text, not raw numeric spelling or whitespace.

Member offsets accept fully consumed unsigned decimal/0x/0X hexadecimal and must not exceed INT32_MAX. UEP_TotalSize must be positive. Optional offset:position[:length[:storage]] uses decimal bitfield components, defaults length/storage to1/1, permits storage1/2/4/8 and validates every bit extent. Vtable offsets are byte offsets aligned8 within INT32_MAX and reject colon tuples. Schema/member existence, total-size meaning and runtime layout binding remain with the parent. No numeric target facts were invented; test engine5.7 metadata is an explicitly owned parser fixture declaration.

Manual checked accumulation rejects uint32 overflow before multiplication/addition. Limits:8MiB/file,16384 layout entries/file,512bytes/name/value token. At most16385 sections/file including NativeLayout prevents empty sections bypassing bounded entry storage. Layout metadata keys are a fixed9-field set. Allocation failure retains standard C++ exception behavior; syntax/refusal throws std::invalid_argument with fixed filename/line diagnostics. No caller-visible partial result is published.

Host ASan/UBSan controls pass89 assertions, including exact entry limits, maximum offsets, bitfield defaults/full64-bit width, malformed/overflow/sign/trailing numeric input, duplicate/Unicode/malformed/list names, all missing/invalid metadata fields, identity disagreement, CRLF/BOM, opaque literal preservation/control refusal, input bounds, retained output after source text disappears and staged failure preserving an existing result. Red link first confirmed the missing ParsePair implementation. Initial strict host compile warnings for signed digit/byte conversions were removed through explicit checked casts; final host/native diagnostics are empty.

Actual PS5 SDK compiles the same production source into build-1/NativeLayoutFiles.o, a genuine ELF64 x86-64 relocatable object. Native execution and full production integration were not performed. Earlier artifacts stay unchanged. build-1/result.json records exact source/header/test/commands/object hashes and scope.
