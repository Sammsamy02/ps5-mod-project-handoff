# Native stdio consumer adaptation

Ready recipe: `final-native-1/integration-units.json`. Replace exactly the original `luaraw-lauxlib`, `luaraw-liolib`, and `fmt` constituent objects, and add the separately hidden `verification-3/owned-fgetc.o`. Do not stack the proof group on the old monolith. The selected fmt object is `final-native-1/fmt.o` with upstream `FMT_USE_FALLBACK_FILE=1` and `-O1`. Original objects, early attempts and O0 variant in verification-3 are retained.

The two isolated Lua source copies replace ordinary getc calls with fgetc and bypass SDK feof/ferror/clearerr FILE-field macros via parenthesized public function calls. The POSIX unlocked configuration branch remains unchanged. Source diffs and source/object hashes are retained. The owned hidden fgetc uses one unsigned byte through fread and returns EOF on a zero read; its only undefined provider is fread. No FILE fields, fake state, import aliases or invented OS identities are used.

fmt's supported fallback formats to a memory buffer and writes via public fwrite, retaining public error handling and stream locking. Allocation, flush timing and optimization differ. All 355 production native commands and source/include roots were surveyed: no FMT_HEADER_ONLY definitions, no other explicit format-inl.h users, and no other objects define the private FILE implementation. No contradictory cross-unit implementation configuration was found. All original strong definitions are preserved; none of the 601 eliminated weak fmt definitions is required by another production unit. See fmt-config-boundary-audit.json and fmt-o1-cross-consumer-check.json.

Native compilation used actual x86_64-sie-ps5. ARM64 and x86_64 host checks passed for adapted Lua file loading/read semantics, the owned fgetc real-stream controls (all 256 byte values, ungetc, EOF and actual read error), and fallback fmt buffering, long writes, recursive locking, concurrent whole records and write-error behavior. Original Lua controls passed. Both original fmt controls asserted at format-inl.h:1673 and entered abort/reaping timeouts; they did not pass, so no original/fallback observational-equivalence claim is made. Public-contract fallback checks passed. See verification-3/receipt.json and individual stdout/stderr/commands.

The isolated replacement group has no undefined __isthreaded, __srget, getc, putc_unlocked, flockfile, funlockfile or fgetc; fgetc is locally defined. Other unrelated Lua/fmt dependencies remain. Its public requirements were already provided or required by native-local-deps-3/attempt2, without new unknown identities. The final integrated scope still retains getc from SDK libc++.a[iostream.cpp.o] and __isthreaded from safe-libc libc.a[arc4random.o]; root's fresh native-local-deps-4/attempt1 map includes both members. This work does not replace those archives. See retained-archive-stdio-users.json for archive hashes and actual map lines.
