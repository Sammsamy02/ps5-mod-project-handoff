context and program-factory overloads accept a copied source. NativeLoaderFacts
and resolver collection layouts are unchanged.

Admission checks structural PT_LOAD coordinates, actual immutable RX/RO bytes
and normalized relative effects against one exact retained ModuleSnapshot.
The same read lease then covers the original mapped resolver and genuine bounded
Rust witness. Only requested Tick slot 10, explicit SelectUniqueAfterNoMatch and
original exact NoMatch/status 3 can publish a translated candidate. All witness
ranges must match; code results must be in file-backed executable bytes and
actual leased RX. Callbacks run after lease release.

SCE executable types follow the retained SDK definitions. Execute-only ELF flags
never assert readable access; the actual lease must provide it. File-only flags 0
metadata is excluded from runtime translation. Unrelated mutable globals/BSS,
imports and existing static TLS remain the original loader's responsibility.
RELRO may provide stricter permissions. Supported RELA forms and bounded parser
limits match the reviewed Rust endpoint; arbitrary ELF encodings are not claimed.
