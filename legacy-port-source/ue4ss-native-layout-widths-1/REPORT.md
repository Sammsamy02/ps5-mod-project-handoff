# Source-derived native accessor widths

GetAccessorWidth(class_name, canonical_key) returns optional<uint32_t> in RC::Platform::NativeLayouts. The table covers419unique non-bitfield/non-UEP_TotalSize canonical schema entries.405have genuine ptr_cast accessor bodies in current generated port source;14legacy FArchive canonical aliases have no body and return unavailable. No game offsets/default layout tables are generated.

Widths use sizeof actual getter return value after remove_cvref and sizeof-if-complete. This resolves genuine nested aliases when accessible, including TUObjectArray.Chunks_Type. For private scalar/recognized pointer getters the source-declared ptr_cast value type supplies the width rather than treating access visibility as size1; FField.ClassPrivate is thus its actual FFieldClass* width. Multiple genuine accessor alternatives require every width to be available and use the maximum. This can conservatively reject a narrower version-specific representation, but bounds every supported source accessor. Missing getter declarations, inaccessible unsupported alias types and incomplete value types return unavailable, never1.

Actual PS5 SDK compilation passed in native-3. The production-only object contains lookup/table; separate controls-2 fixture object is excluded. Actual SDK static controls pass FField.ClassPrivate/UObjectBase.ClassPrivate pointer widths, UObjectBase.InternalIndex_Private int32, FUObjectItem.Object, TUObjectArray.NumElements/Objects/Chunks, UStruct.PropertiesSize and explicit incomplete/void/unknown refusals. UFunction.Func is explicitly unavailable because its native member-function alias/getters are private in current port; UStruct.SuperStruct includes a forward-only legacy value type; UWorld.EditorViews is incomplete. These are honest unsupported keys rather than silently narrow bounds.

Compiler-evaluated constants extracted from the own controls ELF produce303available and116unsupported entries in coverage.json. This extraction uses actual target-compiled sizeof values; it executes no native code and assumes no host width equality. Provenance records exact generated source file/line/getters/casts and schema pins. Every unknown result is enumerated.

Retained native-1 diagnosed undeclared source-only pointer names outside their class scopes; corrected generator to use genuine declarations. Native-2 passed initial controls; native-3 moves controls into separate fixture source. Controls-1 retained two overly broad supported-key assertions; controls-2 explicitly verifies those unsupported states. Initial extraction assumed an unavailable objcopy binary, so the retained byte-identical fixture was read with genuine LLVM readelf. No production bytes changed after integration-units publication.

This is current compiled port type-width evidence, not game ABI/layout validation. Root binder remains responsible for rejecting supplied unsupported keys and bounding widths against the caller-declared total size. Actual SDK game layout declarations/correctness remain a separate target-artifact obligation. No game/process reads, console contact or runtime engine execution occurred; root files/public engine layouts were not modified.
