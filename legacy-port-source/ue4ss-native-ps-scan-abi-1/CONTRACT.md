# ps_scan shared ABI and explicit mapped caller

PsScanAbi.h preserves the original native C++13bool config,5callback context and result field layout. Config size13, context56, EngineVersion4, result96 bytes on x64. C pointer declarations use the existing reference-based wire convention; this adds no provider implementation. Native CharType and PsChar16 are exactly wchar_t,2bytes. Rust uses16-bit code units; callback messages are NUL-terminated, read-only despite original mutable C++ declaration, expire at return and must not unwind or be retained. Valid typed bool fields are required, never arbitrary serialized bytes.

Requested mandatory slots are GUObjectArray, GMalloc, FNameCtorWchar, StaticConstructObjectInternal and EngineVersion. Requested FNameToString, FTextFString, hash tables, GNatives, console function, tick, build configuration and stats are optional. Genuine upstream resolves its full collector before config gating; image/collector errors still fail. Config controls handling, not scheduling. Disabled result fields remain untouched. Requested address failures clear their slot and mandatory misses add errors. EngineVersion failure adds an error while preserving the previous version. Build configuration0meansunknown,1shipping,2development,3test; stats0unknown,1off,2on independently. Genuine ScanGame does not enable FTextFString and always requests config/stats. slots.json retains per-slot semantics.

Mapped ABI V1 consists of explicit pointer/length/runtime-address/permission spans, format and bounded metadata extents. runtime_address must equal the actual supplied pointer. Missing metadata is exactly{0,0}; nonempty metadata must lie wholly in supplied readable spans. No file RVA, serialized label, process lookup or numeric address alone authorizes bytes or a runtime pointer. PsMappedImageCaller retains the actual NativeProgramContext ModuleSnapshot and its own immutable descriptor vector for a synchronous call, checks exact snapshot-readable coverage while allowing splits, and rejects added bytes/gaps/overlap/bad metadata. It does not establish actual permission or engine identity. Root must hold its genuine owned-service read lease and derive permissions before calling Rust; hints are not authority.

Output roles: FNameToString/FNameCtor/StaticConstruct/FText/hash getter/tick and console singleton resolver are function entries; ConsoleManagerSingleton specifically returns a function root from string references, despite its name. GMalloc is a global pointer slot used as FMalloc**; GUObjectArray and GNatives are data addresses. Output range/permission validation remains root integration scope. The static GU CFG fallback candidate is not a verified mapped result.

Verification:64 layout assertions per C/C++/Rust mirror; original declaration extraction size/alignment/offset/callback equivalence compiled on native and host;15 genuine ModuleSnapshot/NativeProgramContext owned controls; C++↔Rust13bool/10owned-pointer-field roundtrip plus5UTF16 callbacks including surrogate pair under host C++ASan/UBSan. Native C/C++ and core-only Rust controls compile with actual SDK/target. No native execution, console access, resolver success stub or ps_scan provider is defined. Do not compose any control object/main into production.
