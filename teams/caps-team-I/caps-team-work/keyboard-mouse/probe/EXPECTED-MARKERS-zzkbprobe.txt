# zzkbprobe v1 -- EXPECTED-MARKERS (Team I2, 2026-10-13, Mac-only until launched)
# Read-only probe: asks the game's own PlayerController IsInputKeyDown(key)
# about 30 times a second (game thread, via LoopAsync + ExecuteInGameThread,
# at most one queued poll at a time) and logs key up/down changes.
# It registers NO key binds and writes nothing. main.lua is 2193 bytes
# (< 4096 admission cap); the loadlist row must carry the exact size.
# Decode the log with harvest/decode_session_log.py, then grep "[kb]".
# Keys watched (Unreal key names): F8 F7 A SpaceBar Enter LeftShift
# LeftControl LeftMouseButton RightMouseButton Gamepad_FaceButton_Bottom
# (the last one = controller Cross, the built-in positive control).

## Startup
[kb] Z0 v1 keys=10        script ran. ABSENT -> not admitted (size row) or mods off.
[kb] PC found             local player controller found (re-found after map loads).
[kb] CAP fn=1 rt=boolean  the engine function answered. fn=0 + error text = the
                          function or the FKey argument does not work on this
                          engine: probe stops after 30 failures ("STOP fail=30").

## Edges (at most 240 lines, then "EDGE cap=240")
[kb] DN <key> n=<i> t=<s>   key went down     [kb] UP <key> n=<i> t=<s>   key went up

## Every 10 s
[kb] SUM v1 polls=<n> pc=<0|1> fn=<-1|0|1> edges=<n> fail=<n> F8=<n> F7=<n> ... Gamepad_FaceButton_Bottom=<n>
  polls should grow by about 300 per 10 s (30/s). Much less = the game
  thread is busy (loading) -- fine; zero for minutes = queue not draining.
