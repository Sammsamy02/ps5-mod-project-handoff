# Launch card: capability #4 (early loading / the map that is already loaded)

**What this launch checks:** when mods start, they also get the map that is already loaded (as on PC, in the same order). The runtime never tries a LoadMap code-detour on PS5. A startup timeline is recorded on one clock.

**What gets built:** the live candidate tree plus cap #4. The live tree is R11 plus these R12 follow-ups:
- LuaMod: `refuse()` split into `emit_counted()`.
- LuaMod: a new counted line `[R12-WORLD] object-index-not-usable-yet-60s` (shown only if the world route is still waiting after 60 s).
- UObjectGlobals: one comment.
- The build stamp, regenerated by the pipeline.

**Rollback:** R11 `bfd95db6` (last clean build).

**Already known, not part of this launch's PASS/FAIL:** Leon's checkered grey/white textures and the outdoors looking too bright. Both were there before this build. They belong to the pak work (#7/#8/#12), not cap #4.

## Before the launch (integrator)
- Patch applied to the live tree (pinned base, no `--allow-drift`). `tests/run_tests.sh` passes. Gates pass (no-detour: 0 LoadMap notes).
- Built once. `verify_build --manifest` PASS. Readback sha + magic, row-check. Same mods as launch 14. Game offline.
- Every console action needs the user's OK for that action.

## What you do
1. Start Townfall. Wait at the title/menu for about 1 minute (the runtime arrives about 70 s after the game starts).
2. Load the save. Play 2 minutes. Use the F7 item menu once.
3. Go through one door or area change if you can.
4. Quit the game. Then the logs are collected.

## PASS (all of these)
- All mods work, no stutter, and no hitch at the moment mods start.
- Log has `[EARLY] stage=loadmap-native state=off reason=ps5-no-code-detours`.
- Log has NO `Failed to add hook` line for LoadMap and NO `[R3] LoadMap deferred arm` line.
- `[EARLY] stage=mods-started ... mods=7`, then `stage=startup-hooks ... loadmap_pre=1`, then `stage=replay-request ... replay=requested`.
- `[EARLY] stage=startup-replay ... decision=replay` (or `none`) with **`snapshot_ms` at or under 20**.
- `[EARLY] stage=first-map-seen ...`, then `[WORLD-EV] LoadMap post delivered`.
- Last `[WORLD-EV] stats ... dropped=0 errors=0`. Self-test at least 161/168.
- `early_timeline.py` prints `VERDICT: PASS`.

## Roll back to R11 if
- Crash or freeze, a mod stops working, stutter at load, or a hitch when mods start.
- `[EARLY] ... decision=skip-index-unusable`.
- `early_timeline.py` FAIL on K3 (a LoadMap detour was attempted) or on K4-K7 (startup map wrong, missing, or delivered with drops or errors).

## Not a rollback
- `early_timeline.py` INVESTIGATE (K1 clocks differ, K2 timeline out of order, K8 snapshot over 20 ms): read the timeline first. If the game felt fine, these are questions for the logs, not faults.
- `decision=skip-ambiguous`: INCONCLUSIVE (a map change was in progress). Repeat once and wait longer at the menu.
