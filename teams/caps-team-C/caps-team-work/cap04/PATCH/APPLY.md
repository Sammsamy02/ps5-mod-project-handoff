# Cap #4 — how to integrate (integrator only)

Mac-only staging. Nothing here has been built, deployed or launched.

## What the patch changes (3 files, 25 exact-once replacements; review fixes in FIXES.md)

| File | Change |
|---|---|
| `src/LuaMod.cpp` | **E1** The PS5 deferred LoadMap *detour* arm (`try_deferred_loadmap_arm`) and its 2 call sites are removed. On PS5 the startup branch is now unconditional and the old eager detour block is compiled out (`#else`), so no code-detour registration is reachable on PS5. `loadmap_state` = 3 from startup, and WORLD-EV owns LoadMap. |
| `src/LuaMod.cpp` | **E2** WORLD-EV startup replay: the route never goes live before startup has closed (first feed after the start gate; feed and `note_index` both check it). Once it is live, the Actors that already existed are fed through the existing `observe()` before any newer object. The map that was already loaded (or loading) gets the normal LoadMap pre → InitGameState → BeginPlay → LoadMap post, ahead of later maps. More than one live GameState skips the replay with a Warning (fail closed). Late registrations get no replay. |
| `src/LuaMod.cpp` | `[EARLY]` timeline lines plus `early_first_pump` diag event. Also fixes an early return that would have stalled the replay when a collect brought no new objects (found by the host simulation). |
| `src/UObjectGlobals.cpp` | **E3** `r9_index_snapshot_live()`: a read-only list of live slots for wanted classes. A slot whose object no longer names the recorded class (freed and refilled since the last sync) is skipped, so `Want` only ever sees the class a live object names now. |
| `src/UE4SSProgram.cpp` | **E4** `[EARLY] stage=mods-started`, the `early_mods_started` diag event, and the `early4_mods_started()` call after the start gate (PS5 only). |

Generic: no game or mod names, no new offsets, no new imports. Rule: data-only hooks, no detours.

## Steps

1. Pick the base. **The build base is the live candidate tree** = R11 + the R12 follow-ups:
   - `LuaMod.cpp`: `refuse()` split into `emit_counted()`; the `[R12-WORLD]` counted line `object-index-not-usable-yet-60s` / `accepted-pending` when the route is still pending after 60 s.
   - `UObjectGlobals.cpp`: one comment (free + refill between two syncs).
   - `GeneratedBuildStamp.hpp`: regenerated by the build pipeline.
   Its hashes are pinned (`candidate-R12-20261012T2159`, LuaMod `96e8ff4d…`), so `--allow-drift` is not needed:
   `python3 -B PATCH/apply_cap04.py --tree <copy> --write`, then on the real tree `--tree <candidate> --write --in-place`.
   If the live tree moved again, the script refuses: re-stage (re-run the tests, check the anchors) instead of forcing `--allow-drift`.
   R11 (`bfd95db6`) is also pinned, for review only (`PATCH/cap04-vs-R11.diff`). Review diff against the build base: `PATCH/cap04-vs-live-R12.diff`.
2. Re-run `sh tests/run_tests.sh` against the integrated tree. T1g/T6 cover the live tree. If the tree moved again, re-stage.
3. Gates before compile: `fs_throw_gate.py`, `no_detour_gate.py`. Expected: PASS with **0** LoadMap detour notes (R11 had 4). Also run `syntax_check_tree.py` for luamod / program / uobjectglobals.
4. Optional: add the 7 markers in `PATCH/markers-cap04.json` to `markers-declared.json` with `add_build_markers.py`, so `verify_build --manifest` requires them.
5. The one independent review is done (`REVIEW.md`, PASS-WITH-FIXES); its fixes are folded in (`FIXES.md`). Build once. Then `verify_build.sh --manifest`, decrypt-off readback, and the row-check, as usual.
6. After the launch, once the game is closed and the logs are harvested, run:
   `python3 -B PATCH/tools/early_timeline.py --ue4ss <ue4ss log> --diag <supplier-diag.jsonl> --klog <klog.decoded.txt> --json <evidence dir>/early-timeline.json`
   Verdicts: PASS; FAIL (a runtime fault, e.g. K3 a LoadMap detour attempt, K7 drops/errors); INVESTIGATE (K1 clocks differ, K2 timeline out of order, K8 snapshot over 20 ms: read the timeline, not a rollback); INCONCLUSIVE.

Review diffs: `PATCH/cap04-vs-live-R12.diff` (build base) and `PATCH/cap04-vs-R11.diff` (23 hunks each). Supersedes ChatGPT's `deferred-arm-stage` (see NOTES.md).
