Raw imports are independently predicted from the exact selected ELF/AR bytes before the actual `ld.lld -r` invocation. Ordinary object roots and lazy archive extraction close to an exact expected unresolved set; the real `llvm-nm` result must equal it. The receipt records the ordered input pins and extracted archive members. This computation matches both the actual 391-input BASE artifact and the independently linked #10 component with BASE fixed libraries. Unsupported linker selection flags and zero/duplicate inputs fail.

Final providers are computed later, after actual packaging bootstrap and current runtime objects exist. Their real global definitions and linker boundaries are accounted for before any remaining strong name is treated as a platform import. Exact NID, module/library names and versions, and FUNC/OBJECT kind are read from saved provider ELF bytes and matched to the pinned SDK declaration. Kernel aliases use the module/library family already evidenced by the pinned inherited contract and a matching real exported row. A missing or ambiguous provider stops before the partial link and Packager. The new typed references use a separate table, preserving the original 16-slot getter table, count and source.

The source packager retains its existing 20 static checks and exact final identity verifier. It additionally binds final kinds and counts to the computed contract. Constructor/finalizer expectations are the sum of every actual pinned bootstrap input and the actual runtime, independently checked against combined and packaged arrays. Twin, count, static-check or constructor failure prevents a FINAL receipt. Source scripts are copied into the package directory so their existing `__file__`, NuGet and receipt paths retain their real meaning.
